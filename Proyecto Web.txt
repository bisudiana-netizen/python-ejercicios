PASO A SEGUIR PARA INSTALAR Y EJECUTAR EL PROYECTO desarrollado con Django

Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:
* Python 3.x
* Django
* pip (gestor de paquetes de Python)
* venv (módulo para entornos virtuales)
* Instalación de algunas extensiones (SQLite Viewer).

Pasos:
